# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

MATLAB project that inverts wood's complex permittivity from Keysight VNA S21 transmission measurements (18–44 GHz). Studies microwave dielectric anisotropy between parallel and perpendicular grain orientations.

## Entry points and running code

All scripts are self-contained `.m` files run directly in MATLAB (R2018b+). No build system.

- **`run_wood_inversion.m`** — Main inversion. Set `WORK_MODE = 1` (batch inversion) or `2` (tables from saved `.mat` results). Contains all five optimization algorithms inline.
- **`plot_wood_comparison.m`** — Post-processing: generates 4 comparison figures from `results_Wood/` `.mat` files. Run after `run_wood_inversion`.
- **`n_scan_diagnosis.m`** — Diagnose loss model by scanning exponent `n` with `fmincon`. Requires Optimization Toolbox. Expects pre-existing `Data_LargeWood_Vertical_Proposed.mat`.
- **`simulations/run_tmm_inversion.m`** — Upgraded inversion using TMM + Debye model (3-parameter). The preferred pipeline.
- **`simulations/exp1_identifiability.m`** through **`exp6_tmm_layered.m`** — Standalone validation experiments.
- **`simulations/group_meeting_figures.m`** — Generates 6 presentation-quality figures.
- **`simulations/synthesis.m`** — Loads experiment outputs and prints summary.

## Required MATLAB toolboxes

- **Statistics and Machine Learning Toolbox** — `lhsdesign` (Latin hypercube sampling), used in all inversion scripts
- **Signal Processing Toolbox** — `sgolayfilt` for data smoothing; code degrades gracefully if missing
- **Optimization Toolbox** — `fmincon`, only needed by `n_scan_diagnosis.m`

No third-party toolboxes or packages.

## Data files

- **`lzmwoods/`** — Raw Keysight VNA CSV files (air reference + 4 wood samples at parallel/perpendicular grain). `load_measurement.m` parses these.
- **`lzmwoods/results_Wood/`** — Inversion output `.mat` files (one per sample per algorithm). `plot_wood_comparison.m` reads from here.
- **`simulations/results/`** — Simulation experiment outputs.
- **`simulations/meeting_figures/`** — Presentation figures generated by `group_meeting_figures.m`.

## Hardcoded paths

`run_wood_inversion.m` line 16-17 hardcodes `dataDir = 'D:\woods\lzmwoods'`. If you move the repo, update these paths. Several other scripts (`n_scan_diagnosis.m`, `plot_wood_comparison.m`, `run_tmm_inversion.m`) also use absolute paths derived from this directory.

## Architecture

### Physical models (in order of sophistication)

1. **Power-law loss tangent (4-param):** `epsilon*(f) = eps_r * (1 - j * tand_ref * (f/30GHz)^n)`. Fabry-Perot transmission. Used in `run_wood_inversion.m`.
2. **Debye relaxation (3-param):** `epsilon*(f) = eps_inf + delta_eps / (1 + j*f/f_relax)`. With caliper-measured thickness, inversion becomes well-posed. Used in `simulations/run_tmm_inversion.m`.
3. **Layered TMM + Debye:** Models wood as alternating earlywood/latewood layers with Chebyshev-accelerated transfer matrix method. `simulations/exp6_tmm_layered.m`, `simulations/run_tmm_inversion.m`.

### Forward model data flow

```
Raw CSV → load_measurement() → air normalization (S_mat/S_air) →
IFFT group delay estimation → |S21| > -80 dB truncation →
Savitzky-Golay smoothing → downsample to ~1000 points →
Optimizer (DE/CMA-ES/GA/PSO/Hybrid) → cost_func_scalar_wood() →
theoretical_T_wood() → [eps_r, tand_ref, n, d]
```

### Optimization algorithms

All five are implemented inline in `run_wood_inversion.m` with LHS-OBL initialization:

- **Hybrid DE-CMA-ES** (proposed): DE pop 100 + CMA-ES pop 100, exchange elites every 60 generations
- **Standard DE**: pop 30, F=0.3, CR=0.6
- **Standard CMA-ES**: pop 10, sigma=0.2
- **Standard GA**: pop 30, SBX crossover (eta=21), mutation rate 0.15
- **Standard PSO**: pop 35, w=0.7, c1=c2=1.5

### Cost function

`cost_func_scalar_wood` combines: 0.5 × Huber magnitude loss + 0.25 × Huber phase loss + 0.3 × group-delay constraint (couples optical path to thickness) + 0.05 × thickness regularization. The group-delay term is key to breaking the d–tand degeneracy.

## Key research findings

- 4-parameter power-law model is fundamentally underdetermined due to (tand, n) and (eps_r, d) coupling
- Debye model with caliper-fixed thickness (3-parameter) is well-posed — the breakthrough configuration
- Relaxation frequency stable around 1–4 GHz, consistent with bound-water Debye relaxation
- Clear dielectric anisotropy: epsilon_parallel systematically higher than epsilon_perpendicular
